# Spec — Art Pipeline (models, rigs, animation)

**Owners:** Erick (cat), Brianna (kids, VFX), Javier (environment props), Andrew (Cut-world & mission props) · **Requirements:** NFR-ART-*

## 1. Formats and budgets
| Asset | Triangles | Textures | Format |
|---|---|---|---|
| Cat | 5,000–8,000 | 1024 px | FBX (mesh + skeleton), one FBX per animation |
| Kid | 4,000–6,000 | 1024 px | FBX |
| Prop | 300–2,000 | 512 px | FBX (GLB only if FBX fails) |

Tools: **Tripo AI** first, Meshy / Hyper3D as fallback.

## 2. Character workflow
1. Generate the model (text or image → 3D) in a neutral pose: quadruped standing for the cat, A-pose for kids.
2. Reduce to the budget (low-poly / remesh); textures to 1024 px.
3. Auto-rig: **Quadruped** for the cat, **Humanoid/Biped** for kids.
4. Animate on that same skeleton. All animations **in place** (no root motion), 30 fps.
5. Export one FBX with mesh + skeleton, then one FBX per animation. Names: `A_Cat_Walk`, `A_Kid_PointShout`…
6. Import into Unreal: mesh first (creates the skeleton), then each animation targeting that skeleton. Scale 1.0. Check the cat is ~45 cm long without tail.
7. **The cat skeleton is frozen once approved.** Do not re-rig after animations exist.

## 3. Cat
Approved look: stocky solid-black cat, no white markings (Tripo model, ~10,600 triangles, one 2048 px texture).

Prompt: `low poly stylized chubby solid black cat, stocky round body, short thick legs, no white markings, standing on four legs, neutral pose, tail straight back, mouth closed, game asset, clean topology`

**Current files**

| File | What it is |
|---|---|
| `SourceArt/Characters/Cat/Source/Cat_Tripo.fbx` + `T_Cat_BaseColor.jpg` | Original Tripo export, untouched. Note: it already has an open gap in the middle of the back. |
| `SourceArt/Characters/Cat/SK_Cat.blend` | Rig + walk cycle, editable in Blender 5.3 |
| `SourceArt/Characters/Cat/SK_Cat.fbx` | Export of the .blend: mesh + skeleton + `A_Cat_Walk` (what Unreal imports) |
| `Tools/Blender/rig_cat.py` | Rebuilds the two files above from `Cat_Tripo.fbx` |
| `Tools/Python/import_cat.py` → `build_cat_materials.py` → `build_cat_character.py` | Import into Unreal, build `M_Cat_Toon` / `M_Cat_Hologram`, then `ABP_Cat` / `BP_Cat` (run in this order, editor closed) |

**Materials** (all values are material parameters, tune them in a material instance):

| Material | Look |
|---|---|
| `M_Cat_Toon` (default) | Cartoon look of Tripo's viewer: two-tone cel shading from the sun direction, soft rim light, glowing eyes, on Tripo's texture. Unlit and exposure-compensated, so it reads the same in any lighting. |
| `M_Cat_Hologram` | Glitch look, recreating Tripo's "hologram" viewer style: translucent teal, bright edges, a grid fixed to the body, a light band sweeping up the cat, flicker and short sideways glitch jumps. |

Tripo's viewer styles (hologram, clay…) are not part of the exported files: every FBX/GLB export only carries the base color texture, so these looks are rebuilt as Unreal materials.

The mesh is only rotated to face +X, placed with the paws on the origin and uniformly scaled to 45 cm (nose to rump); its shape is not edited. Skeleton (28 bones, root `root`): `pelvis` › `spine_01`–`spine_03` › `neck` › `head`; `tail_01`–`tail_05`; `hind_thigh/shin/foot/toe_{l,r}`; `front_scapula/upper/lower/paw_{l,r}`. Weights are generated by distance to each bone, limited per region (legs, tail, head).

Only `A_Cat_Walk` exists today: 16 frames at 30 fps (0.53 s), lateral-sequence walk, in place. At play rate 1 it covers 30.6 cm/s; `ABP_Cat` advances it by the distance the cat actually moves, so the paws do not slide at any speed. The rest of the table below is still to be made on the same skeleton.
